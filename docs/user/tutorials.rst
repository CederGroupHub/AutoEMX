Tutorials
==================

AutoEMX can be used in two ways; follow the tutorials of the one you prefer:

- **GUI**: point-and-click interface in your browser, running locally on your computer. It
  covers acquisition, quantification, clustering analysis with interactive 3D plots, and
  single-spectrum fits.
- **Scripts**: Python scripts in ``autoemx/scripts/`` where you edit the parameters and run
  them, e.g. for automation or batch processing.

Both run the same engine and write the same sample folders, so you can switch between them:
for example, acquire with a script and analyse the results in the GUI.
